# 药典基原提取与归并

## 理解用户请求并确定来源

- 从白话提取查询范围（全量或指定条目）、所需条目类型、基原分类和交付物。“我要查找全部真菌类药材的基因组”指全查「药材和饮片」目录正文，其后筛选真菌基原，再查公开组装。“帮我制作一个中药材的基因组库”默认覆盖该目录全部药材基原。“含真菌药材的中成药”读取制剂处方并关联药材基原。
- 优先使用用户指定的药典、版本和卷册。已提供原文时直接读取，并记录版次、条目名和页码或章节。默认使用 [2025 年版一部官方网络版](https://2025.chp.org.cn/#/database?bookId=1) 和 [颁布公告的一部目录](https://app.www.gov.cn/govdata/gov/202503/26/525844/article.html)。对其他版次查询其官方来源。
- 对 PDF 优先提取文本。扫描页使用可用的 OCR，并对照页面核对拉丁名、作者缩写、种下等级和跨页的基原句。无法确认的字符保留疑点。

## 读取官方网络版

从 Skill 目录执行以下命令。脚本依赖 Python 3.10+ 与 curl，使用公开网页的只读查询，输出标题、在线页码、正文链接和基原段或处方段。使用同一输出文件重跑可继续未完成的条目。指定药材或制剂时，用可重复的 `--title` 参数精确定位。

```text
python scripts/pharmacopoeia.py materia-medica --output herbs.json
python scripts/pharmacopoeia.py formulas --title 桂枝茯苓丸 --output formulas.json
```

- 逐条对照目录和读取报告的 `catalog`、`selection`、`entries`，核对目标范围。正文读取失败、段落缺失或格式变化时，打开对应网页复核并记录状态。无法完成的条目列入待补查。只有确认全部目标条文和分类状态后才标为全量。
- 依据基原段对条文分类。真菌类包括以真菌组织或药典明确的真菌与宿主复合体为来源的药材，例如冬虫夏草。以动物为主体且描述真菌参与的条目单列相邻范围，例如僵蚕。检查疑似条目的拉丁学名与分类依据，网页关键词和药材中文名只用于定位。

## 提取和匹配

1. 从每条药材的基原描述中提取药材正名、基原生物中文名、拉丁学名原文（含命名人）、药用部位及出处。并列基原逐个拆开，保留与各自部位或限定条件的对应。分别记录条目标题中的拉丁药材名和基原生物学名。记录基原类别，按药典条文处理明确的复合体和非生物性来源。
2. 保留原文，另建检索名称。仅在同一段落中属名指代明确时展开缩写，保留杂交符号及种下等级。按生物类群选择分类来源，例如植物用 [Kew POWO](https://powo.science.kew.org/)，真菌用 [Species Fungorum](https://www.speciesfungorum.org/) 或有标本证据的分类论文。记录查阅日期或数据版本，先按全名、命名人和等级核对，再沿同物异名关系追踪到接受名。只有中文名或疑似 OCR 错字时，候选名称须回到原文核实。保留药典中的历史用名，对涉及种概念差异的结果记录样本与鉴定证据。
3. 分类匹配逐条记录为接受名直配、同物异名映射或待核对。记录所匹配的名称及接受名、接受名记录的标识和链接。只有有明确证据且指向同一接受分类单元的记录才自动合并。不同主干观点冲突且无法裁决时，保留候选及其出处，暂停自动归并。

## 归并和交付

- **基原明细**按药典条目与基原的组合逐行输出。列出药材名、原植物中文名、原文学名、部位、条文出处、匹配状态和接受名标识。跨版本记录分别保留。
- **物种检索清单**按同一主干的接受标识归并，每个物种一行。汇总关联药材、药典原名和已确认的同物异名，保留回查明细的关联。可核实的种下分类单元可按权威记录归入其所属物种以便检索，同时在明细和检索词中保留种下身份。杂交分类单元与亲本保持独立。
- 用接受学名和确认的异名构造检索词。一个药材对应多个物种时，在对应的各物种行中保留该药材。同一植物的不同药用部位保留在基原明细。
- **待核对清单**列出原始条目、问题、候选和需要补查的证据。交付前核对每条目标基原明细都进入了至少一个可追溯的检索条目或待核对清单，并报告处理范围、提取数量、归并后数量及未决数量。
- **基因组目录**将确认的基原交给[多库组装检索](genome-sources.md)。用户要求 Excel 时交付基原与组装表，并保留出处和逐库覆盖记录。
