# 药用植物基因检索

## 提取 tRNA

收到查找或提取 tRNA 的请求时，先确认药典基原及目标分区，再按[从注释提取 tRNA](references/trna.md)逐套处理。已有可用 tRNA 注释的参考直接提取。缺少可用注释时才对对应参考运行 tRNAscan-SE。

## 从药典生成检索清单

收到建库、按类查药材、匹配基原或追溯中成药组成的请求时，按[药典基原提取与归并](references/pharmacopoeia.md)判定范围并读取条文。未提供文件或指定其他版次时，默认读取 2025 年版《中国药典》一部官方网络版。用户要求基因组时，按[多库组装检索](references/genome-sources.md)查询已核对基原。NCBI、GWH 和用户指定的库均须查询。保留版本化登录号、提交物种、菌株、组装级别、数据库链接和逐库状态。

逐物种检查检索报告中的 `literature_followup`。对列出的基因组类型执行[从原始论文追溯组装](references/genome-sources.md#从原始论文追溯组装)，核实论文使用的参考版本和公开获取入口，再选择用于后续处理的组装。

明确要求下载参考时，先核定要保留的登录号和版本，再按[批量下载参考](references/genome-sources.md#批量下载参考)运行本地队列。后续 tRNA 处理复用已下载文件。下载进度以本地 JSON 报告为准。

## 确定检索对象

- 将药材俗名对照到植物学名，记录同物异名及来源。一种药材可能对应多个基原，来源未确定时按物种分别检索。
- 从用户提供的植物、化合物、通路、基因名或编号出发。化合物有同名、异构体或缩写歧义时，用结构标识或上下文核对。
- 已给出品种、基因组组装或注释版本时优先使用它。未指定版本时，记录实际采用的版本。

## 检索和核对

1. 已知基因名或编号时，优先查对应物种的原始数据库记录。基于化合物检索时，先从原始研究提取相关反应、酶和已报道基因，再核对目标植物的基因记录。
2. 用论文补充材料、原始基因组门户或 NCBI 记录核对编号。保留来源使用的基因、转录本和蛋白编号类型。跨注释版本或数据库只有在找到映射依据时才合并条目。
3. 逐条标注证据。区分目标物种中的直接功能实验、遗传或表达关联、同源推断和自动注释。记录实验实际覆盖的物种、底物和反应。异源体系实验应注明表达体系，跨物种推断应注明参考物种和依据。
4. 对数据库注释与论文不一致的条目，列出分歧并核查编号、版本和实验条件。找不到原始记录时，标记待核对并说明已查范围。

## 返回结果

简述检索对象和采用的数据版本。候选有多条时，用表格列出物种、基因及编号、关联反应或化合物、证据类型、原始记录或论文链接。编号或组装版本缺失时写明缺失。涉及推断时，明确列出依据和关键证据缺口。
